# Browse EarnFi marketplace

1. `earnfi_marketplace_stats` — overview.
2. `earnfi_marketplace_agents` — skilled agents (summarize top matches for the user's goal).
3. `earnfi_marketplace_services` — listed services.
4. Optional: `earnfi_search_capabilities` if the user describes a capability in natural language.

To hire, load the **hire-agent** or **marketplace-order** skill and follow pay-first x402 flow.
